# Windmill Docs — 非公式日本語訳

[Windmill](https://www.windmill.dev/) のドキュメントを、個人的な学習のために
日本語へ訳しています。

## 読みかた

**GitHub 上でそのまま読めます。** サイトは建てていません。

👉 **[日本語訳の目次](./docs/INDEX.ja.md)**

訳は原文の**隣**に `.ja.md` として置いてあります。

```
docs/intro.mdx        原文
docs/intro.ja.md      訳
```

こうしているのは、別ツリーにすると **904 件の画像参照と 4135 件のリンクが全部
壊れる**から。同じディレクトリなら、どちらも書き換えずに動きます。

未訳のページへのリンクは**英語のページに着地します**。それが正常で、訳が無いことの
表明です。

## 訳を足す

```sh
node scripts/mdx-to-ja.mjs docs/core_concepts     # 骨組みを作る（既訳は上書きしない）
# …散文を訳し、冒頭の「未訳。」の行を消す…
pnpm run check:ja                                 # 落ちを見つける
pnpm run index:ja                                 # 目次を作り直す
```

生成器がやること: `@site/` の import を落とし、`<DocCard>` を箇条書きのリンクに直し
（絶対 `/docs/…` は相対パスへ。mirror に無いページは本家サイトへ）、`<Tabs>` を
見出しにし、本家にしか無い部品には「ここには無い」と置きます。

### 訳すときの決め事

| | |
|---|---|
| 訳語 | [GLOSSARY.ja.md](./docs/GLOSSARY.ja.md) で固定。`worker` `lockfile` `webhook` `CLI` は訳さない |
| コードフェンスの中 | **1 文字も変えない。** コメントも英語のまま（画面に出るものと食い違わせないため） |
| リンク先・画像のパス | 変えない。リンクの**文字列**は訳してよい |
| 画像の alt | 英語のまま |
| 製品名の見出し | 訳さない（`PostgreSQL` `BigQuery` など） |
| UI の文字列 | 「日本語（English）」の形で併記 |
| ページ内リンク | 訳した見出しに合わせて飛び先を書き換える |

### 検査が見るもの

`scripts/check-ja.mjs` は原文から骨組みをその場で作り直し、訳と突き合わせます。

- リンク先と画像のパスが**多重集合として**一致するか（同じ URL が 2 回出るページで
  1 つ消しても気づけるように）
- コードブロックの**中身**が原文とバイト単位で一致するか
- ページ内リンクの飛び先が、**その訳自身の見出し**に在るか（id は `github-slugger`
  に計算させる。自前の正規表現で書いていたときは 133 本中 12 本で食い違った）
- 見出しの数が階層ごとに合うか
- 散文にキリル文字やハングルが紛れていないか（実際に 2 件あった）

**この検査は落ちを見るだけで、訳の質は見ません。** 質のほうは目で読むしかない。
