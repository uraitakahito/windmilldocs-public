# Scripts quickstart

Windmill supports scripts in TypeScript, Python, Go, PHP, Bash, C#, SQL and more.

<div className="grid grid-cols-2 gap-6 mb-4">
	- [TypeScript (Deno, Bun, Node.js)](https://www.windmill.dev/docs/getting_started/scripts_quickstart/typescript) —— Write your first Windmill script in TypeScript.
	- [Python](https://www.windmill.dev/docs/getting_started/scripts_quickstart/python) —— Write your first Windmill script in Python.
	- [Bash / Powershell / Nu](https://www.windmill.dev/docs/getting_started/scripts_quickstart/bash) —— Write your first Windmill script in Bash / Powershell / Nu.
	- [Go](https://www.windmill.dev/docs/getting_started/scripts_quickstart/go) —— Write your first Windmill script in Go.
	- [SQL & query languages](https://www.windmill.dev/docs/getting_started/scripts_quickstart/sql) —— Write your first Windmill script in PostgreSQL, MySQL, MS SQL, BigQuery or Snowflake SQL.
	- [PHP](https://www.windmill.dev/docs/getting_started/scripts_quickstart/php) —— Write your first Windmill script in PHP.
	- [Docker](https://www.windmill.dev/docs/getting_started/scripts_quickstart/docker) —— Windmill supports running any docker container through its Bash support.
	- [Rest / GraphQL](https://www.windmill.dev/docs/getting_started/scripts_quickstart/rest_graphql) —— Write your first Windmill script in Rest / GraphQL.
	- [Rust](https://www.windmill.dev/docs/getting_started/scripts_quickstart/rust) —— Write your first Windmill script in Rust.
	- [Ansible](https://www.windmill.dev/docs/getting_started/scripts_quickstart/ansible) —— Write your first Windmill script in Ansible.
	- [C#](https://www.windmill.dev/docs/getting_started/scripts_quickstart/csharp) —— Write your first Windmill script in C#.
	- [Java](https://www.windmill.dev/docs/getting_started/scripts_quickstart/java) —— Write your first Windmill script in Java.
	- [Ruby](https://www.windmill.dev/docs/getting_started/scripts_quickstart/ruby) —— Write your first Windmill script in Ruby.
	- [R](https://www.windmill.dev/docs/getting_started/scripts_quickstart/r) —— Write your first Windmill script in R.
	- [dbt](https://www.windmill.dev/docs/getting_started/scripts_quickstart/dbt) —— Run an unmodified dbt project as a Windmill script.
</div>
