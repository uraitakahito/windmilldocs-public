# スクリプトのクイックスタート

Windmill は TypeScript・Python・Go・PHP・Bash・C#・SQL などでスクリプトを書けます。

<div className="grid grid-cols-2 gap-6 mb-4">
	- [TypeScript (Deno, Bun, Node.js)](https://www.windmill.dev/docs/getting_started/scripts_quickstart/typescript) —— TypeScript で最初のスクリプトを書く。
	- [Python](https://www.windmill.dev/docs/getting_started/scripts_quickstart/python) —— Python で最初のスクリプトを書く。
	- [Bash / Powershell / Nu](https://www.windmill.dev/docs/getting_started/scripts_quickstart/bash) —— Bash / Powershell / Nu で最初のスクリプトを書く。
	- [Go](https://www.windmill.dev/docs/getting_started/scripts_quickstart/go) —— Go で最初のスクリプトを書く。
	- [SQL とクエリ言語](https://www.windmill.dev/docs/getting_started/scripts_quickstart/sql) —— PostgreSQL・MySQL・MS SQL・BigQuery・Snowflake SQL で最初のスクリプトを書く。
	- [PHP](https://www.windmill.dev/docs/getting_started/scripts_quickstart/php) —— PHP で最初のスクリプトを書く。
	- [Docker](https://www.windmill.dev/docs/getting_started/scripts_quickstart/docker) —— Windmill は Bash 対応を通じて任意の Docker コンテナを実行できます。
	- [Rest / GraphQL](https://www.windmill.dev/docs/getting_started/scripts_quickstart/rest_graphql) —— Rest / GraphQL で最初のスクリプトを書く。
	- [Rust](https://www.windmill.dev/docs/getting_started/scripts_quickstart/rust) —— Rust で最初のスクリプトを書く。
	- [Ansible](https://www.windmill.dev/docs/getting_started/scripts_quickstart/ansible) —— Ansible で最初のスクリプトを書く。
	- [C#](https://www.windmill.dev/docs/getting_started/scripts_quickstart/csharp) —— C# で最初のスクリプトを書く。
	- [Java](https://www.windmill.dev/docs/getting_started/scripts_quickstart/java) —— Java で最初のスクリプトを書く。
	- [Ruby](https://www.windmill.dev/docs/getting_started/scripts_quickstart/ruby) —— Ruby で最初のスクリプトを書く。
	- [R](https://www.windmill.dev/docs/getting_started/scripts_quickstart/r) —— R で最初のスクリプトを書く。
	- [dbt](https://www.windmill.dev/docs/getting_started/scripts_quickstart/dbt) —— 手を加えていない dbt プロジェクトを、Windmill のスクリプトとして実行する。
</div>
