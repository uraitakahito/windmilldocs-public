# 訳語

21 本を跨いで訳語が揺れるのが、この翻訳でいちばん起きやすい失敗です。
`intro.ja.md` で使った語を種にして、ここで固定します。

## 中心的な語

| 原語 | 訳 | 補足 |
|---|---|---|
| script | スクリプト | |
| flow | フロー | |
| app | アプリ | |
| runnable | 実行対象 | script / flow / app の総称 |
| workspace | ワークスペース | |
| resource | リソース | |
| variable | 変数 | secret variable は「秘密の変数」 |
| schedule | スケジュール | |
| trigger | トリガー | |
| deploy | 配備 | |

## 訳さない語

固有名か、日本語の定訳が英語のままのもの。

| | 理由 |
|---|---|
| **worker** | Windmill の実行単位の固有名。「作業者」では通じない |
| webhook / OAuth / CLI / API | 定訳が英語 |
| lockfile | 同上 |
| Docker / Git / VS Code | 製品名 |

## 画面に出る文字列

**「日本語（English）」の形で併記します。**

> 「実行（Run）」を押します。

読者が実際の画面と突き合わせられなくなるのを防ぐためです。Windmill の UI は
英語なので、訳語だけを書くとどこを押せばよいか分からなくなります。

## 訳さない部分

| | |
|---|---|
| コードブロックの中身 | **一切触りません。** コメントも原文のまま —— 画面に出るものと食い違わせない |
| CLI のコマンド・パス・ファイル名 | そのまま |
| リンク先・画像のパス | **1 文字も変えません。** ここが壊れると読めなくなります |
| frontmatter | `description` の値だけ訳します |

## 文体

- 常体（だ・である）ではなく **敬体（ですます）**。原文が読者に語りかける調子なので
- 「〜することができます」より「〜できます」
- 原文の太字・箇条書き・見出しの構造は保つ。**訳で構造を変えない**
  （`scripts/check-ja.mjs` がずれを見つけます）
